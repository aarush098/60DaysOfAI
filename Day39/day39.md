# Day 40

## AI Assistant Builder

## What I Learned

- Learned how to build a custom AI assistant using Claude AI.
- Configured the assistant through guided MCQ questions instead of writing prompts manually.
- Generated a complete HTML-based AI assistant application.
- Understood the difference between running the assistant as a Claude Artifact and as a standalone HTML application.
- Learned that Claude Artifacts work without an Anthropic API key inside Claude.ai.
- Understood that a valid Anthropic API key is required when hosting or running the HTML application independently.
- Tested the assistant with sample user queries.
- Explored the generated system prompt and understood how it controls assistant behavior.
- Reviewed the documentation panel to understand the assistant's features and configuration.
- Improved understanding of AI assistant design, prompt engineering, and deployment workflow.

## Key Learnings

- AI assistants can be created without writing complex prompts manually.
- MCQ-based configuration makes assistant creation simple and beginner-friendly.
- System prompts define the assistant's personality, behavior, and capabilities.
- Claude Artifacts provide an easy way to test AI applications directly within Claude.
- Standalone HTML applications require an Anthropic API key for live AI responses.
- Testing and reviewing the generated assistant helps ensure better user experience.
- Proper documentation and screenshots are important for project submission.
